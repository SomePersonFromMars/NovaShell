# NovaShell
A custom shell implementation developed as part of the **Operating Systems** course at **Theoretical Computer Science, Jagiellonian University, Cracow**.

## Getting Started

### Prerequisites
- A Linux-based operating system
- GCC compiler or equivalent

### Building NovaShell
```bash
cd shell
mkdir bin
make bin/novash
```
